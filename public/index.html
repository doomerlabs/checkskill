Scan from the terminal

Send your Markdown as the request body to get JSON findings.

curl --fail-with-body -sS \
  -H 'Content-Type: text/markdown' \
  --data-binary @SKILL.md \
  https://checkskill.ai/api/scan

For folders, send JSON with a files array of {path, content} objects. Scans accept up to 10 MiB of text and 384 files.

How CheckSkill works

Check the exact revision you’re about to install or publish.

From published audits to deterministic checks

We study public Snyk reports on Skills.sh, look for recurring patterns, and write rules that flag those patterns in skill files. CheckSkill shows the passages behind its findings, so you can review the evidence and rerun the same checks after an edit.

What the forecast means

CheckSkill predicts what Snyk might flag. It can miss findings or flag additional issues. Skills.sh publishes the original audits from each provider. About Skills.sh audits ↗

Why it’s free

Each scan runs rules without a model call. That keeps scans inexpensive enough to offer for free, with no account required.
