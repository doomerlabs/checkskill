Use CheckSkill from your terminal

Send your Markdown as the request body to get JSON findings.

curl --fail-with-body -sS \
  -H 'Content-Type: text/markdown' \
  --data-binary @SKILL.md \
  https://checkskill.ai/api/scan

On macOS, create an unlisted link and open the skill in your browser. Use xdg-open on Linux.

link=$(curl -fsS \
  -H 'Content-Type: text/markdown' \
  --data-binary @SKILL.md \
  https://checkskill.ai/api/open) && open "$link"

Use POST /api/share to get the same link in JSON. All three routes also accept application/json with a skill string. Skills can be at most 64 KiB. Share links have a separate 24,000-character limit for the compressed source in the URL.

Why CheckSkill exists

A skill can tell an agent what to run, which content to trust, and what to report to you. CheckSkill highlights instructions worth checking before you publish or install a skill. It’s free and works without an account.

Skills.sh publishes audits from Gen Agent Trust Hub, Socket, and Snyk. Those hosted classifiers run on their providers’ infrastructure. CheckSkill runs its own rules on the exact text you provide, including unpublished revisions, and shows the passages behind each finding. The references point to related checks from other scanners. A clear scan only means these rules found no matches. Skills.sh audits
